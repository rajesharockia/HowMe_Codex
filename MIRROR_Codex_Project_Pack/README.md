# MIRROR Codex Project Pack

This folder contains the complete MIRROR product brief plus a set of visual references.

- `MIRROR_Codex_Brief.md` — product strategy, MVP scope, UX, safety/privacy guidance,
  technical direction, Codex prompts, and embedded relative image links.
- `assets/` — full concept board and individual interface reference crops.

Open the Markdown file in VS Code or GitHub with the `assets/` folder beside it.
The images are illustrative design references, not production UI or scientific predictions.
